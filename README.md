Waypoint — Internship Discovery & Tracker

Overview

Waypoint is a web-based MVP designed to help Indian college students discover internship opportunities and organise their application process in one place.

Problem

Students often discover opportunities across multiple platforms, making it difficult to organise relevant roles, keep track of applications, and manage deadlines.

Target Users

Indian college students aged 18–24 looking for internships in product, technology, business, marketing, and analytics.

Core Features
1.Discover: Browse internship opportunities.
2.Search & Filter: Find roles based on relevant criteria.
3.Saved Opportunities: Bookmark roles for later.
4.Application Tracker: Organise applications by status.
5.Demo Listings: Sample opportunities used to test the product experience.

Product Thinking

The MVP focuses on reducing friction between discovering an opportunity and keeping track of the application process.

Tech Stack

1.React
2.TypeScript
3.Vite
4.Tailwind CSS

Current Status

Early-stage MVP. Opportunity discovery and application tracking are implemented using sample data. Real vacancy verification and broader user testing remain future improvements.

Next Steps

1. Add verified internship listings and source links.
2. Conduct usability tests with students.
3.Prioritise improvements based on user feedback.
